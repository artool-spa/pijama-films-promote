# dev-docs-update

Update existing development documentation with current progress.

## Purpose
Keep dev docs synchronized with actual work completed.

## Updates

### plan.md
- Mark completed tasks
- Add newly discovered tasks
- Update blockers
- Revise estimates

### context.md
- Add new decisions
- Document problems solved
- Note file changes
- Update integration details

### tasks.md
- Move completed tasks
- Update in-progress status
- Add new tasks
- Prioritize next steps

## Usage
Run `/dev-docs-update` periodically during feature development and before context resets.

## When to Update
- After completing major milestones
- When making architectural decisions
- Before taking a break
- When encountering blockers
- Before requesting help
