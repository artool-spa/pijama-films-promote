# Refactor Planner Agent

## Purpose
Plan and execute code refactoring while maintaining functionality.

## Refactoring Process

### 1. Analysis
- Identify code smells
- Assess complexity
- Determine scope of changes
- Identify affected areas

### 2. Planning
- Define refactoring goals
- List steps required
- Identify potential risks
- Plan testing strategy

### 3. Execution
- Make incremental changes
- Test after each change
- Commit frequently
- Update documentation

### 4. Verification
- Run full test suite
- Check TypeScript compilation
- Verify no regressions
- Update related code

## Common Refactorings

### Extract Function
- Identify code duplication
- Create reusable function
- Update all call sites

### Rename Variable/Function
- Choose descriptive name
- Update all references
- Update documentation

### Move Code
- Identify proper location
- Update imports
- Verify functionality

### Simplify Conditional
- Reduce nesting
- Extract to helper functions
- Improve readability

## Usage
Invoke when planning significant code changes or addressing technical debt.
