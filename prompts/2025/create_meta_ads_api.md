# Create Meta Ads API

## Context

This application is for promoting independent films vía renting in a customized "MUVI" application


## Definitions

- Each "Producer" has a campaign in the ads account
- Campaigns will be optimized by conversion with pixel
- Each promotion will be an adset with their own budget, start date, end date, segmentation and more than one ad
- It should be able to create an ad preview using video or images
- Only one access token
- Stats should be on adset and ad level


## Considerations

Database structure will be reformulated

## Goal

Create an API that supports this definition
